# 一键回收包裹物品[!]

一键回收包裹物品的脚本命令


  格式：


TakeBagItem 物品名称(支持多个物品)  收取数量 每个物品增加元宝值 每个物品增加金币值 每个物品增加泡点值 每个物品增加泡点经验值 变量(保存实际回收的物品数量) 聚灵珠经验(为空或0时不增加聚灵珠经验 1时同时聚灵珠经验) 是否显示提示信息(0或空：显示；1：不显示） 颜色值(空或*回收所有；0-255回收对应颜色物品)


[@main]


  #ACT


  TakeBagItem 木剑|布衣(男)|布衣(女) 46 0 0 0 10000 N1 0


  SENDMSG 6 成功回收<$STR(N1)>个木剑，布衣(男)，布衣(女)，价格为10000经验








----------------------------------------------------------------------------------
