# 字符串比较处理

功能：


字符串比较处理。


格式：


  CheckContainsText 字符 字符串检查 //检查字符串是否包涵在另外一个字符串中.


  CompareText 字符 字符 // 比较两个字符串是否一样


;==========================================


  检查字符串是否包涵在另外一个字符串中


  [@Test]


  #IF


  CheckContainsText www.Geem2.com Geem2.com


  #Say


  包涵


  #elsesay


  不包涵


  ;==========================================


;==========================================


  比较两个字符串是否一样


  [@Test]


  #IF


  CompareText www.Geem2.com www.Geem2.com


  #Say


  一样


  #elsesay


  不一样


  ;==========================================
