# 杀死怪物时触发,杀怪触发

功能: 杀死怪物时触发

说明:

对应地图参数中需要加入ONKILLMON才可生效!

[@OnKillMob]

#IF

CheckKillMonName

白野猪

#SAY

你杀死一头白野猪!


;=============================================================

人物杀死怪物时触发


[@KillMon]


#ACT


SENDMSG 7 你杀死<$KILLMONNAME>


break


英雄杀死怪物时触发


[@HeroKillMon]


#ACT


SENDMSG 7 你英雄杀死<$H.KILLMONNAME>


break



注： 英雄杀死怪物触发需要在英雄设置打开选项，否则共享人物触发
