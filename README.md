## 🤖 LLM / RAG 使用指南

本仓库针对大语言模型检索做了以下优化：

1. **语义化文件名**：每篇文档以命令/功能的中文名命名，而非 `page_1.html`
2. **YAML Frontmatter**：每篇文档包含 `title`, `category`, `source_file` 元数据
3. **RAG 索引**：`rag_index.json` / `rag_index.csv` 提供完整的文档级元数据，可直接导入向量数据库
4. **适度拆分**：每篇文档聚焦单一命令或功能，天然适合作为 RAG chunk
5. **代码块保留**：脚本示例使用 Markdown 代码块，便于 LLM 理解和复制

import json

with open("rag_index.json", "r", encoding="utf-8") as f:

# 按分类筛选
