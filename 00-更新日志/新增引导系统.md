# 新增引导系统

功能：引导一快可以点击的区域.


命令：GUIDE 类型 触发ID 控件ID 提示文字


引导一快可以点击的区域，点击以后会触发QF字段的 [@ClientGuideX]


X代表 触发ID



-------------------------------------------------------------

类型=0时

自定UI里的控件引导

参数1=0

参数2=触发ID

参数3=(0=主界面

2=人物装备栏3=人物背包栏4=英雄装备栏5=英雄背包栏6=聊天框左侧龙界面7=聊天框右侧等级界面8=商铺界面9=时装界面,10=英雄时装，11=技能栏，12=英雄技能栏，13=称号栏，14=英雄称号栏，15=状态栏，16=英雄状态栏，17=属性栏，18=英雄属性栏，19=人物出战栏，20=行会界面,21=详细属性位置,

22=宠物界面,23=宠物背包，24=人物首饰，25=英雄首饰，26=人物神佑，27=英雄神佑，28右侧切换按钮，29任务界面)

参数4=引导提示文字

参数5=控件名(类名获取查看自定义UI的控件标题)


示例：

GUIDE 0 1 3 点击整理一下

DItemBagArrange

-------------------------------------------------------------

类型=1时

道具引导

参数1=1

参数2=触发ID

参数3=(0=人物背包栏

1=人物装备栏)

参数4=引导提示文字

参数5=道具唯一ID


示例：

GUIDE 1 1 0 双击使用物品

3023

-------------------------------------------------------------

类型=2时

按钮引导

参数1=2

参数2=触发ID

参数3=(BUTTON的触发序号)

参数4=引导提示文字


示例：

GUIDE 2 1 1 引导1号按钮


-------------------------------------------------------------

类型=99时

NPC界面引导

参数1=2

参数2=触发ID

参数3=(新脚本前的编号ID)

参数4=引导提示文字


NPC脚本   引导的脚本信息必须带ID
